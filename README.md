# OSMAN BEY COLLECTION Website

A responsive, multilingual corporate landing page (English, Turkish, Arabic).

## Publish with GitHub Pages
1. Upload `index.html` to the root of the repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then Save.
5. GitHub Pages will provide the public website URL.

Replace the sample imagery and add verified company contact details before launch. The page intentionally does not invent phone numbers, email addresses, project claims, or certifications.

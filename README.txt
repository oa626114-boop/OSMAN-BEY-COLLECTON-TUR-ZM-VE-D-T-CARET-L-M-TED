OSMAN BEY COLLECTON — Website package

Files:
- index.html: multilingual company website (Arabic, Turkish, English)
- assets/: company logo and image assets for the hero and seven business activity cards

To publish with GitHub Pages:
1. Create a separate repository named osman-bey-collectton.
2. Upload index.html and the entire assets folder to the repository root.
3. Open Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
